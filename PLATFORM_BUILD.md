# FARMOS Device Compute Platform

Updated November 11, 2026. The earlier discovery questionnaire is superseded by the [current build and coder handoff](docs/CURRENT_BUILD_AND_CODER_HANDOFF.md).

## Product direction

Use consenting, eligible devices to execute useful customer-funded work, verify delivery, record actual costs and confirmed revenue, then repeat when net economics support it. Optimize net profit per device-hour. Device count, utilization, test credits and token estimates are not earnings.

Start with an owner-operated Android pilot using existing workloads. Evaluate other devices separately; do not promise iPhone background execution or Stratus C7 compatibility without a physical-device test. FARMOS owns its customer job supply and orchestration; optional external adapters remain subject to certification.

The coder should extend the existing repository, not rebuild it. Priority is closing customer isolation, network egress and billing gaps around PR #8, then proving one end-to-end paid workload. Live payouts require a real provider and reconciliation; the shipped simulated provider is insufficient.
